# OdinDuo 2.0.2-beta.3

Draft notes for a candidate on top of beta.2. The USB guard script and restoration protocol are unchanged.

- **Automatic helper replacement:** the helper records the app version code it was launched with. When protection starts and a running helper has no matching marker (an older APK), OdinDuo stops it with confirmed USB restoration and starts the bundled helper. A helper from the same version is adopted as before.
- **Plain status titles:** "Protection is off", "Waiting for your screen", "Touch is protected" and "Needs your attention", in English and Dutch.
- **Roadmap:** [ROADMAP.md](../../ROADMAP.md) lists planned usability work.

- **Lifecycle review fixes:** every service cleanup waits for prior restoration, even when destroyed before launch. This prevents a later cleanup from releasing a new session while an older Stop remains pending. Delayed onboarding also waits behind all dashboard dialogs, not only setup and screen help.

## Signing and installation

Version code is **24**. The APK must be signed with the same private release key as beta.1 and beta.2; the key is held by the maintainer and is never committed. A debug-signed build must not be published as a release.

## Validation and limits

- GitHub CI (debug and instrumentation APK build, unit tests, lint, policy and shell lifecycle checks) passed for the change merged in #8.
- **Not yet validated:** updating from an older APK with an active helper on a physical Odin 3. This must be tested before the tag is published.
- No signed APK has been built from this source and no VirusTotal scan exists.
