# OdinDuo 1.1.0 — release candidate

Version code 10; same package and signing certificate as 1.0.0 and the 1.1 betas. This candidate is prepared for a stable release after the outstanding physical checks pass.

## Changes

- Fresh helper health and atomic power observations keep Protected accurate, including during busy logging. Auto protect can recover helper loss after confirmed USB restoration, with a limit on repeated failures and grace that excludes deep sleep.
- Restoration reads back the original power settings and retains recovery snapshots on failure. Retry confirms cleanup before replacing the previous helper, including when its session marker is missing.
- A failure notification and dashboard action offer **Retry protection**. Starting a fresh session clears the old failure notification after cleanup.
- An Android Quick Settings tile starts Auto protect or stops protection, follows status changes while its panel is closed and exposes switch semantics when newly added. Existing tiles may need removing and adding again to refresh accessibility semantics.
- **Check setup** reports the stock AYN service, Android profile, notifications, background restrictions and battery optimisation. Help keeps paragraph breaks and theme changes do not repeat the notification prompt.
- Maintenance: target SDK 36, AppCompat 1.8.0, Gradle 9.8.0 and an icon resource folder appropriate for the minimum Android version. The required vendor reflection has a documented lint exception scoped to its lookup method; this does not remove the dependence on stock AYN firmware.
- CI builds a debug APK, runs Android lint and runs the policy/shell checks for every PR. Debug artifacts use CI's development key and cannot replace a public release installation in place.

## Upgrade

Install `OdinDuo-1.1.0.apk` over the existing app once released. **Stop protection once, then enable Auto protect again** to start the updated helper. A SHA-256 checksum accompanies the signed APK. No private signing key is included.

## Validation and release gate

- The 1.1 beta's policy, shell and Android 15 emulator checks are recorded in [beta.1](1.1.0-beta.1.md) and [beta.2](1.1.0-beta.2.md).
- Physical beta.2 validation on stock Odin 3: the tester reported no problems after the requested five sleep/wake cycles and two detach/reconnect checks. Raw measurements are pending retrieval. The actual Retry notification and Quick Settings checks remain pending.
- SDK/dependency maintenance: local debug/release builds, policy/shell checks and Android 15 emulator regressions passed. Both lint variants report zero issues, with the vendor reflection exception documented above. The signed release candidate is non-debuggable and retains the public signing certificate. Stock-device final-candidate checks remain pending.
- GitHub Actions passed on both the branch and PR. `main` requires an up-to-date PR and the **Android build and checks** result from the GitHub Actions app, including for administrators. The repository requires no separate reviewer for this single-maintainer workflow.

Battery impact remains unmeasured. Other devices and firmware combinations are unverified. Automatic brightness synchronisation remains unavailable on the tested setup; use the Retroid screen's hardware controls and the app's brightness guide.
