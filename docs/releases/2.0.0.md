# OdinDuo 2.0.0

OdinDuo 2.0.0 makes the working Odin 3 + Retroid Dual Screen protection easier to understand and support.

## What’s new

- A cleaner dashboard shows the current protection state, connected display, live session duration and the Odin’s whole-device battery level when Android exposes it.
- **Session history** keeps a small local timeline of starts, stops, reconnects, recovery and test results. It is bounded, can be cleared, and is included in the support export.
- A first-run setup guide points to the stock AYN service check, Android background settings, notification permission and the Quick Settings tile.
- **Connection & wake test** provides a short manual checklist for touch now, touch after sleep/wake and touch after reconnect. OdinDuo stores only the result, never touch coordinates.
- Ongoing protection remains quiet in its low-importance notification channel. Recovery failures use a separate actionable channel with **Retry protection**.
- English remains the default. Dutch can be selected through Android’s per-app language settings.

## Install

Download `OdinDuo-2.0.0.apk` and its `.sha256` checksum from this full release. The package remains `nl.retroid.touchguard`, the version code is 20, and the release is signed with the existing certificate so it can update 1.1.0 without uninstalling. Stop protection, install the update, and enable Auto protect again. Never publish or share the signing key.

## Validation

- Local debug and signed release builds pass. Both Android lint variants report zero issues.
- GitHub CI passes the Android build, lint and existing policy/shell regression checks.
- The release APK is non-debuggable, targets Android SDK 36 and retains the existing signing certificate.
- The 2.0.0 build has not yet been tested on stock Odin 3 hardware for repeated touch after sleep/wake, reconnect, recents dismissal, Quick Settings, notification Retry or an in-place upgrade from 1.1.0. Earlier physical touch validation applies to 1.1.0; it is not a new 2.0.0 test result.
- The new checklist is a manual report of the user's checks. It does not independently verify Retroid input delivery or distinguish an unchecked step from a failed or unperformed check. New Android UI and history-concurrency regressions have not been run.

If you experience a regression, Stop protection, export diagnostics and report the model, firmware and steps in the repository. Keep the installation and its signing key; Android normally prevents installing the lower-version 1.1.0 APK over 2.0.0.

Automatic brightness synchronisation remains unavailable on the tested Odin 3 + Retroid Dual Screen hardware. Use the Retroid display’s hardware controls with the existing brightness guide.
