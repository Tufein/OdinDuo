# OdinDuo 2.0.2-beta.1

This prerelease improves action feedback on top of stable **2.0.1**. It retains that version's current-boot session checks, helper recovery, elapsed timing, language handling and bounded history.

- Starting, recovery and stopping show a progress indicator. Start and Stop display explicit in-progress labels, and Auto protect explains when its setting is being updated.
- Pending requests survive rotation and activity recreation within the same boot. Controls wait for service acknowledgement, with a bounded UI timeout. Saved requests from another boot are discarded. A timeout does not claim that protection started or that restoration succeeded.
- First-run setup continues to wait for an unanswered notification permission request after rotation. It opens after the answer while the activity is resumed.
- Errors put Check setup and Share diagnostics beside Retry. Android refusing a Stop request produces an explanation instead of crashing the dashboard.
- The notification-settings shortcut has keyboard focus and a minimum 48 dp touch target. New labels are available in English and Dutch.

## Signing and installation

The APK uses a **new release signing certificate**. Its package is still `nl.retroid.touchguard`, with version code 22, but it cannot update existing public 2.0.1 or earlier installations in place.

Before changing installations, open the currently installed app, tap **Stop protection**, and wait for confirmed restoration. If restoration fails, keep the app and use its recovery controls. After successful restoration, preserve any diagnostics you need, uninstall the old installation, and install this APK. Uninstalling removes app settings and logs. Auto protect starts off after the fresh install; allow notifications and enable it again if desired.

New signer SHA-256: `eed6825524ba2bd056241dc5c98a94ce244dd93294a9701357d13f38261e5f96`.

The private keystore and password are kept outside Git and release assets. Future builds made with this new key can update this installation. Preserve a secure backup of the key and password.

## Validation and limits

- Nine Robolectric host Android UI tests on API 35 pass, including same-boot recreation/timeouts, previous-boot rejection, Dutch feedback and setup ordering while notification permission is pending.
- Debug APK and instrumentation APK builds pass. Debug/release lint report zero errors and one dependency-upgrade warning each.
- The existing Java and real-shell regressions pass, including current-boot session timing, process identity, reconnects, restoration readback failure/retry and delayed-watchdog isolation.
- A signed, non-debuggable release build is prepared with the new key and its package, version and signer verified.

The instrumentation APK was compiled in this environment; its emulator tests were not executed here. These host checks do not establish physical Retroid touch/sleep behavior. The physical results in the stable 2.0.1 notes apply to that earlier revision.

**VirusTotal has not scanned this APK.** The service is reachable, but the secure API-key binding is missing. No malware-scan result or safety guarantee is claimed. The draft release awaits that requested scan before public APK publication.
