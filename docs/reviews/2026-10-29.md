# Repository review: lifecycle and dashboard

Reviewed main at `ca989a3337523f00ee7ef99c59446aef36b9465c`, open PRs #9 and #5, and the recent Android CI results. The existing checks were green; no open issues were listed.

## Findings fixed

1. **Service cleanup could overtake an earlier Stop.** The startup path waited for the previous restoration barrier, but onDestroy did not. An instance destroyed before its queued startup ran could finish cleanup early and release the next instance while an older cleanup was still pending. Each cleanup now waits for its captured predecessor before issuing Stop. The completion barrier and worker shutdown run in finally. Two host service-lifecycle regressions reproduce single and chained early destruction without a device or privileged Binder calls.
2. **Delayed onboarding covered dashboard dialogs.** Its guard recognized setup and screen-help dialogs only. Opening Appearance before the 450 ms callback, or resuming while that dialog was open, allowed the introduction to cover it. All dashboard dialogs now share active-dialog tracking; the existing duplicate setup guard is retained. A regression covers appearance, brightness, help, history and the connection checklist, including background/resume.

The three new regressions failed against the reviewed source and passed after the fixes. Final local validation: all 29 API 35 Robolectric tests pass with no failures or skips; the six Java regression programs and real-shell lifecycle checks pass. Debug and instrumentation APKs build. Debug/release lint report zero errors and two upgrade-availability warnings each. Instrumentation runtime and physical device tests were not run.
